# Video Object Detection Pipeline (YOLOv8)

This repository contains a video object detection pipeline built with YOLOv8 and OpenCV.

The solution processes video streams frame by frame, applies a pretrained deep learning model to detect and classify objects, overlays bounding boxes and confidence scores, and generates an annotated output video.
It also provides basic detection statistics, supporting visual inspection and analytical validation.

This project demonstrates applied computer vision, highlighting skills in deep learning, video analytics, and end-to-end processing pipelines, suitable for production-oriented and proof-of-concept scenarios.
